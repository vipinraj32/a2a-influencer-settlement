Influencer agents A2A

    How a deal flows

    1. Discover — the Advertiser Agent reads influencer Agent Cards.
    2. Negotiate — parallel A2A offers and counter-offers; the policy engine bounds every move.
    3. Cart Mandate — ZyroXQ (the HSP merchant) creates the order, paying into escrow.
    4. Payment Mandate — after the policy gate (and your approval above the threshold) the wallet signs EIP-3009.
    5. Settle — HSP verifies, settles, and its webhook funds the escrow.
    6. Prove — the verifier checks the video; signed attestations release fixed and performance fees.
